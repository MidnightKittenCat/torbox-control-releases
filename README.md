# TorBox Control releases

Installers for TorBox Control, a desktop app for your TorBox downloads on Windows and Linux.

Download the latest `TorBox-Control-…-setup.exe` (Windows) or `TorBox-Control-…-x86_64.AppImage` (Linux) from [Releases](../../releases/latest). On Windows it installs for your user with no admin rights and adds a Start menu entry. Both keep themselves up to date from here.

TorBox Control is an unofficial app, not made by or affiliated with TorBox.
